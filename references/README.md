## 组织与命名

每组方案放在 `references/<方案名称>/` 中，保留相互关联的文件，并用简短 README 记录用途、来源、文件入口与已知限制。

文件名采用 **名称－用途（需要时）－来源.后缀**，使用英文小写与连字符。用途字段用于说明文件的实际作用；名称和后缀已能表达的信息不重复添加，例如 STL 无需再加 `mesh`。

| 示例 | 含义 |
| --- | --- |
| `drawer-box-deepseek.STL` | 抽屉盒的 STL 参考模型，来源记为 DeepSeek |
| `stackable-drawer-assembly-deepseek.STL` | 可堆叠抽屉的装配参考模型 |
| `stackable-drawer-preview-deepseek.html` | 可堆叠抽屉的概念预览页 |
| `stackable-drawer-generator-deepseek.py` | 可堆叠抽屉的 STL 生成脚本 |

来源可以是生成工具、作者或网站。确定不了来源时使用 `unknown`；按回忆暂记的来源应在方案 README 中说明不确定性。生成日期、模型版本、原始链接和提示词等信息记录在说明中，不必全部写进文件名。新增同名文件时用 `-v2` 等版本后缀区分，保留已有资料。

关联文件改名时同步更新脚本输出名称、文件引用和文档链接。
