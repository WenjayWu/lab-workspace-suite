# 抽屉内部分区构造参考

在现有抽屉内部增加收纳分区，比较可拆隔板和固定隔舱的外形、布局与连接构造。以设计思路为主，具体参数由项目维护者在 SolidWorks 中实现。

## 设计基准

- `drawer-front` 是实际抽拉、容纳物品的完整抽屉；`drawer-box` 是外层容纳与堆叠壳体。
- 抽屉内腔：左右宽 270 × 前后深 260 × 净高 134 mm，来自维护者测量并确认方向。
- 现有抽屉已完成基础设计、打印与使用，以上由维护者反馈确认；本目录新增的分区方案尚未实际建模或试制。
- 绘图使用的隔板厚度、墙高和分格位置只用于观察构造，不是生产参数。

## 四种方案

| 方案 | 分区逻辑 | 主要构造 |
| --- | --- | --- |
| A 可拆插接格栅 | 两条纵板与两条横板组成九格，可减少隔板数量 | 纵板顶部槽与横板底部槽互补，交叉插接 |
| B 可拆长短分区 | 左侧保留贯通长区，右侧分成三格 | 主隔板与短隔板端部搭接，锁止与端部支撑由后续建模完善 |
| C 固定混合分区 | 左侧一大一小，右侧三格，总计五格 | 等高隔墙与抽屉底板一体连接 |
| D 固定高低分区 | 与 C 相同的五格布局，高低隔墙区分区域 | 主隔墙较高、内部隔墙较低，可考虑平滑过渡与拿取空间 |

用浏览器直接打开 HTML，无需联网、安装依赖或启动服务。保持 HTML 与两张 WebP 在同一目录，图片才能正常显示。

- 选择 A–D 切换方案。
- 立体视图可拖动旋转、滚轮缩放；俯视图观察格子分布及抽拉方向。
- 勾选降低前侧外壁以查看内部，这是展示用的剖切效果。
- A / B 的拆分滑杆可观察隔板槽口与拆装关系；C / D 为一体隔舱，拆分功能不可用。
- 点击图片可放大，按 Esc 或点击关闭按钮退出。

HTML 用简化几何示意布局与开槽。图片用于观察外形、圆角和连接细节，AI 生成的拆分件数量、槽口和形状可能与示意存在偏差；不作为尺寸、锁止或配合正确的依据。
